# Changelog

## 0.4.1 — 2026-11-06

- Repaired overcompression in v0.4.0 by restoring concrete, agentic editorial diagnoses for development-language leakage, memo-like writing, generic AI rhetoric, and cross-section manuscript inconsistency.
- Added `references/editorial-diagnostics.md`, with concrete failure signatures, scholarly rewrites, claim-language distinctions, and a writer-first manuscript reading standard; no programmatic checks or review artifacts.
- Strengthened the main skill's development-to-publication firewall and explicitly distinguished research-method calibration from editorial-process jargon.
- Restored function-sensitive anti-defensive editing, the reviewer-to-manuscript firewall, and more detailed evidence status and inferential claim guidance.
- Restored two JF/JFE publication exemplars and Jha-inspired stance, evidence, and style-pattern calibration, while retaining agents' responsibility for introductions, contributions, and results interpretations.
- Preserved the short core, bounded independent reading, and installer-only executable policy.

## 0.4.0 — 2026-11-06

- Rebuilt the skill as concise, manuscript-first scholarly writing guidance. The main skill is under 800 words and routes to six focused references.
- Removed all programmatic writing scanners, hashing and run-state validators, formal-run templates, Python unit tests, behavioral-evaluation harness and scoring rubric, and CI validation workflow. The local installation script is the sole remaining executable.
- Consolidated overlapping prose rubric, section-jobs, research-to-prose lessons, and workflow-adherence modules into the core skill and focused references.
- Made verification an **agentic reading of the actual assembled manuscript**, with direct repair of economic argument, claims, evidence, cohesion, and finance publication voice; independent scholarly reading remains optional after the writer's own review.
- Condensed the scholarly voice and GPT/Codex anti-defensive guidance; retained proportionate evidence checks, nearest-literature positioning, and text-measure distinctions.
- Simplified repository documentation; previous implementation remains available in Git history.

## 0.3.6 — 2026-11-06

- Explicitly included finance-manuscript proofreading and polishing, including single-sentence changes, in skill activation.
- Changed closest-paper positioning to continue substantive writing from verified evidence when neighboring-study information is incomplete, without replacing the assigned draft with a checklist.
- Reframed the regex prose linter as a limited pattern scanner; its CLI and JSON outputs disclaim manuscript-quality and skill-compliance evaluation.
- Prohibited mechanical synonym substitution to game scanner results; added negative-control testing for bad generic finance prose that escapes all configured patterns.
- Updated guidance distinguishing deterministic software tests from agent behavior and scholarly writing quality.

## 0.3.5 — 2026-11-06

- Redesigned the explicitly selected formal-run default as schema v3 around the writer’s integrated reading of the assembled manuscript and current hash checks, with one independent reader only when deliberately chosen.
- Removed score thresholds and reader acceptance decisions as workflow-approval criteria. The optional prose linter remains diagnostic.
- Isolated schema-v1/v2 eight-pass and repeated-review templates in `templates/legacy/`; `--legacy-format` is offered strictly for historical compatibility, and the validator still reads older records.
- Added twelve new deterministic tests for v3 record creation, writer-read freshness, included LaTeX files, optional reader identity and notes, read-only audit mode, and absence of score-driven gating.
- Allowed a genuinely completed integrated reading to retain an unchanged manuscript without inventing a cosmetic edit or producing a reviewer-approval certificate.
- Updated the main skill, research references, documentation, and verification checks to distinguish record validation from scholarly manuscript quality.
